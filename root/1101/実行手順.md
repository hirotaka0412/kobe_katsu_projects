SSH接続が完了している場合、EV3側のターミナルでPythonファイルを指定して実行します。

今回のMediaPipeを使ったEV3制御プログラムを例に説明します。

## 1. EV3上のファイルを確認する

SSH接続後、以下のように表示されている状態から始めます。

```
robot@ev3dev:~$
```

まずファイルを確認します。

```
ls -l
```

`ev3_receiver.py` が存在すれば準備完了です。

## 2. Pythonプログラムを実行する

以下のコマンドを入力します。

```
python3 /home/robot/ev3_receiver.py --speed 20
```

各項目の意味は次のとおりです。

| 項目                            | 意味            |
| ----------------------------- | ------------- |
| `python3`                     | Python 3で実行   |
| `/home/robot/ev3_receiver.py` | 実行するファイル      |
| `--speed 20`                  | モーター速度を20%に設定 |

正常に起動すると、次のメッセージが表示されます。

```
Waiting for PC on port 5000
```

これは、EV3がPCからの動作指令を待機している状態です。

## 3. PC側のプログラムを起動する

EV3側のターミナルはそのままにして、VS Codeで別のターミナルを開きます。

PC側で次のコマンドを実行します。

```
python hand_director.py --host ev3dev.local
```

これでPCのカメラで認識した手の動きをEV3に送信できます。

## 4. プログラムを終了する

- PC側：カメラ画面で `q` を押す
- EV3側：SSHターミナルで `Ctrl + C` を押す

EV3側を停止すると、受信待機プログラムも終了します。

### 補足：一般的なPythonファイルの場合

例えば `test.py` を実行したい場合は、

```
cd /home/robot
python3 test.py
```

だけで実行できます。

注意： 今回のMediaPipeシステムでは、EV3側で実行するのは `ev3_receiver.py` だけです。`hand_director.py` と `hand_motion.py` はPC側で使用します。
