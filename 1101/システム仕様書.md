# OpenCV・MediaPipe・EV3による手の位置を用いたロボット操作
スライドより詳しくまとめました。もっと知りたい人はこちらを参照してください。

## 1. システムの概要

カメラで撮影した手の位置と形をPCで解析し、その結果に応じてEV3ロボットを操作するシステムです。手を画面の上下左右に置くとロボットが移動・旋回し、中央に戻す、手を握る、またはカメラから手を外すと停止します。

画像処理と手の認識はPCで行い、EV3は受信した指令に従ってモーターを動かします。

## 2. システムの構成

```mermaid
flowchart LR
    A["カメラ<br/>手を撮影"] --> B["PC：OpenCV<br/>映像を取得・表示"]
    B --> C["PC：MediaPipe<br/>手の位置・形を認識"]
    C --> D["PC：判定処理<br/>動作指令を生成"]
    D -->|"Bluetooth接続上のTCP通信"| E["EV3<br/>指令を受信・モーターを制御"]
```

| 構成要素 | 役割 |
| --- | --- |
| カメラ | 手の映像を撮影する |
| OpenCV | カメラ映像の取得、鏡像化、色変換、結果の表示を行う |
| MediaPipe Hand Landmarker | 映像から手の各部の位置を推定する |
| 判定プログラム | 手の中心位置と握りの状態から動作指令を決める |
| Bluetooth・TCP | PCとEV3をIP接続し、指令を送る |
| EV3 | 指令に応じて左右のモーターを制御する |

## 3. 動作の流れ

1. **映像の取得**：OpenCVがカメラからフレームを取得し、画面上の左右と操作を合わせるために鏡像化します。
2. **手の認識**：画像をMediaPipe用に色変換し、Hand LandmarkerのVIDEOモードで手のランドマークを推定します。認識する手は最大1つです。
3. **手の状態の判定**：手首と指の付け根の計5点の平均を手の中心とし、その位置と握りの有無から指令を決定します。
4. **指令の送信**：PCが `forward`、`backward`、`left`、`right`、`stop` のいずれかをTCPでEV3へ送信します。
5. **モーターの制御**：EV3が指令を受信し、左右のモーターの回転方向を切り替えます。

## 4. 操作方法

| カメラ画面上の手の状態 | 指令 | EV3の動作 |
| --- | --- | --- |
| 開いた手を上に置く | `forward` | 前進 |
| 開いた手を下に置く | `backward` | 後退 |
| 開いた手を左に置く | `left` | 左にその場旋回 |
| 開いた手を右に置く | `right` | 右にその場旋回 |
| 手の中心が中央の枠内 | `stop` | 停止 |
| 手を握る、または手が映らない | `stop` | 停止 |

- 手の**現在位置**で動作を決めるため、同じ場所に置き続けると動作も続きます。
- 中央の停止領域は、画面中心から横・縦それぞれ画面サイズの18%以内です。斜めの位置では、中心からのずれが大きい軸を優先します。
- 握りの判定は、親指以外の4本のうち3本以上が曲がっているかを距離から推定する簡易方式です。手の向きや指の重なりによって誤判定する場合があります。

## 5. 画面表示

- **黄色い枠**：手の中心が入ると停止する領域
- **緑色の点**：MediaPipeが推定した手のランドマーク
- **紫色の点**：動作判定に使う手の中心
- **PREVIEW / EV3**：プレビュー中かEV3への接続中かを表示
- **forwardなどの文字**：現在の判定指令

## 6. プログラムの構成

| ファイル | 実行場所 | 役割 |
| --- | --- | --- |
| `hand_director.py` | PC | カメラ取得、手の認識、画面表示、EV3への送信 |
| `hand_motion.py` | PC | 手の位置・握りから動作を判定 |
| `hand_landmarker.task` | PC | MediaPipeの手認識モデル |
| `ev3_receiver.py` | EV3 | 指令の受信、モーター操作、通信状態の監視 |

## 7. 通信と停止処理

BluetoothのIP接続を使用し、その上でTCP通信を行います。既定のポート番号は **5000** です。PCは指令が変化したとき、および同じ指令が続く場合にも約0.1秒ごとに指令を送ります。

EV3は指令を約0.5秒受信できない場合や接続が切れた場合にモーターを停止します。PC側の終了時にも停止指令を送る処理があります。ただし、受信プログラムの強制終了やEV3のOS停止など、すべての障害時に停止を保証するものではありません。接続が切れた場合、PC側の自動再接続は行いません。

## 8. 実行手順

### 準備

- PCにPython、OpenCV、MediaPipeを用意し、カメラを接続します。
- PC側の3ファイルを同じフォルダーに置きます。
- EV3にev3devと `python3-ev3dev2` の実行環境を用意し、モーターを左B・右Cに接続します。
- PCとEV3をBluetoothのIP接続で接続し、EV3のIPアドレスを確認します。SSHで使えるホスト名があれば、転送時に使用できます。

PC側で必要なライブラリをインストールします。

```bash
python -m pip install mediapipe opencv-python
```

### PCだけで認識を確認

PC側のファイルを置いたフォルダーで実行します。

```bash
python hand_director.py
```

EV3には接続せず、カメラ画面に判定結果を表示します。`q` キーで終了します。

### EV3を接続して操作

1. PCから受信プログラムをEV3へ転送します。`EV3_IP` は実際のIPアドレスに置き換えます。

   ```bash
   scp ev3_receiver.py robot@EV3_IP:/home/robot/
   ssh robot@EV3_IP
   ```

2. EV3側のターミナルで受信プログラムを起動します。

   ```bash
   python3 /home/robot/ev3_receiver.py --speed 20
   ```

3. PCの別のターミナルで操作プログラムを起動します。

   ```bash
   python hand_director.py --host ev3dev.local
   ```

初回は車輪を浮かせて回転方向を確認してください。モーターの取り付け方により方向が逆になる場合は、`ev3_receiver.py` の `COMMANDS` を調整します。

## 9. 利用上の注意

- 手は1つだけカメラに映し、照明や背景を調整して認識結果を確認します。
- 手の認識には誤差があります。十分なスペースを確保し、すぐ停止できる状態で試してください。
- TCP受信ポートには認証がありません。接続相手が分かるネットワークで使い、必要に応じてEV3側で `--bind EV3_IP` を指定して待受先を限定します。
- この資料は提供されたプログラムとREADMEに基づく説明です。実機での動作、通信、認識精度は利用環境で確認してください。
